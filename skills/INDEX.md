## 阅读路径

**新人 onboarding**（约 1 小时）：

```
SKILL_00 管线总览
  → SKILL_01 底本分层与符号原则
  → SKILL_02 结构切分
  → SKILL_03 实体标注
  → SKILL_04 联语识别
  → SKILL_05 形制校验
```

**接手维护**（约 30 分钟）：

```
SKILL_00 §五 当前基线
  → SKILL_07 规律库（避免重犯已知错误）
  → SKILL_08 文档与版本管理（提交前必读）
```

**换一部书**：

```
SKILL_09 迁移到新文本（先读）
  → 按需回查 01–06
```

## 技能之间的依赖

```
00 管线总览
 ├─ 01 底本分层与符号原则      （无前置）
 │   └─ 02 结构切分            （依赖 01 的底本边界）
 │       ├─ 03 实体标注         （依赖 02 的段落单元）
 │       │   ├─ 03a 人名消歧
 │       │   └─ 03b 词表构建
 │       └─ 04 联语识别         （依赖 02 的段落单元，复用 03 的实体标签）
 │           └─ 05 形制校验     （依赖 04 的 upper/lower）
 ├─ 06 语料构建与渲染          （依赖 03/04 的索引）
 ├─ 07 质量反思与规律库        （贯穿 03–05）
 ├─ 08 文档与版本管理          （贯穿全程）
 └─ 09 迁移到新文本            （元技能，统领全部）
```

**关键约束**：**02 必须先于 03/04 完成**。
段落边界一旦返工，全部编号与标注作废——这是本项目最贵的一次教训。
