# SKILL 03a: 人名消歧

> **核心理念**：**显示名保留原文，规范名服务检索。**
> 消歧不是"统一写法"，而是"给同一个人的多种写法一个共同的索引键"。

---

## 一、任务定义

### 1.1 何时使用

- 同一人物在文中以字号、谥号、别称反复出现
- 要支持"查林则徐写过的联"这类跨写法检索
- 要给人物建索引

### 1.2 输入与产出

| | 内容 |
|---|---|
| 输入 | 已标注 `〖@某某〗` 的正文 |
| 产出 | `〖@显示名\|规范名〗` |
| 前置 | [SKILL_03](SKILL_03_实体标注.md) |
| 后继 | [SKILL_06](SKILL_06_语料构建与渲染.md) 的实体索引 |

---

## 二、问题：联话里的人名

《楹联丛话》中同一人物几乎从不以同一写法出现：

```
尝闻〖@纪文达〗师言……          ← 谥号
盖自叙见〖@朱子〗于集……          ← 尊称
〖@彭文勤〗公连日构思……          ← 谥号
余在邗江，得〖@朱竹垞〗先生大书……  ← 号
```

若不消歧，检索"纪昀"命中 0 次——因为书里从来没有"纪昀"三个字。

---

## 三、消歧语法

### 3.1 内联消歧

```
〖@显示名|规范名〗
```

| 部分 | 作用 | 渲染 |
|---|---|---|
| 显示名 | 原文写法 | 显示在页面上 |
| 规范名 | 唯一索引键 | `title` 属性 + JSON 索引 |

```html
<span class="ent person" title="人名 · 纪昀">纪文达</span>
```

### 3.2 三种消歧方式

| 方式 | 做法 | 成本 | 适用 |
|---|---|---|---|
| **L1 内联** | 标注时直接写 `\|规范名` | 低 | **本项目全部采用** |
| L2 映射表 | 外部 JSON：`{"章": {"短名": "规范名"}}` | 中 | 章内一义、反复出现 |
| L3 全局推理 | 跨书推断活跃期 | 高 | 同名异人且无上下文可判 |

**优先 L1**：标注即消歧，不需要维护任何外部状态文件。

**本项目只用 L1**，理由：全书仅 2,289 段，跨书指代问题远小于长篇史书；
且"Markdown 是唯一事实源"——引入外挂映射表会破坏这一点。

## 四、规范名怎么定

### 4.1 基本原则

> **A87：规范名优先本名（姓 + 名）**

以及 **A110：取消"首次全名豁免"**——
无论首见还是后见，该消歧就得消歧，不能"第一次出现留全名"。

### 4.2 本项目的补充

> **在联话中，谥号与字号是正式称谓，但规范名仍取本名。**

| 规范名 | 显示名（并存的多种形态） |
|---|---|
| 阮元 | 阮芸台、阮云台、云台师、芸台师、芸台先生、阮文达、阮仪征 |
| 苏轼 | 东坡、坡公、苏东坡、苏文忠 |
| 朱熹 | 朱子、朱文公、朱紫阳、紫阳 |
| 林则徐 | 林少穆、少穆 |
| 纪昀 | 纪文达、文达师 |
| 陶澍 | 陶云汀、陶文毅 |
| 梁同书 | 梁山舟、山舟先生 |
| 朱彝尊 | 朱竹垞、竹垞先生 |
| 欧阳修 | 欧阳文忠、欧阳公 |
| 刘墉 | 刘文清、刘石庵 |
| 赵翼 | 赵瓯北、瓯北 |
| 真德秀 | 真文忠、真西山 |
| 徐渭 | 徐文长、徐青藤 |
| 宋荦 | 宋牧仲、宋漫堂 |

**共 14 位**有两种以上并行称谓。

另有 **104 位**虽只出现一种称谓，仍标了规范名——
因为显示名是字号（"彭文勤""龚海峰""张文和"），检索本名更有用。

### 4.3 规范名与显示名不一致的代价

```markdown
〖@纪文达|纪昀〗
```

读者看到"纪文达"，索引键是"纪昀"。
**检索"纪昀"命中，检索"纪文达"在 JSON 层不命中。**

这不是缺陷，是设计。但必须写清楚，否则使用者会困惑：

- 正文检索（grep `.tagged.md`）→ 两种写法都能命中
- 索引检索（查 `entities.json`）→ 只有规范名
- `entities.json` 同时保留 `name`（规范名）与原始 `display`

## 五、何时故意不消歧

**有些同名在原文中就是模糊指代，强行消歧反而破坏原意。**

| 情形 | 处理 |
|---|---|
| 称谓含敬语（"阮云台师"） | 消歧为 `〖@阮云台\|阮元〗师`，敬语留在标记外 |
| 原文确实泛指（"某观察"） | 不标，或只标 `〖;观察〗` |
| 无法判定是哪个同名者 | 不消歧，保持 `〖@某某〗` |

> **宁可少消歧，不可错消歧。**
> 错误的规范名比没有规范名危害大得多：
> 空着时研究者会自己去查，错了会直接引用错误结论。

## 七、检查清单

- [ ] 每个规范名在 `list_entities` 里只出现一次
- [ ] 显示名在原文中确实存在（不要凭空造）
- [ ] 同一人物的所有写法都指向同一规范名
- [ ] 没有两个不同人物被归到同一规范名
- [ ] 敬语（师、公、先生）留在标记外

**自检**：

```bash
# 列出有多种显示名的规范名
python3 - <<'PY'
import re, collections
md = open('data/楹联丛话全编.tagged.md', encoding='utf-8').read()
pairs = collections.defaultdict(set)
for m in re.finditer(r'〖@([^〗|]+)\|([^〗]+)〗', md):
    pairs[m.group(2)].add(m.group(1))
for k, v in sorted(pairs.items(), key=lambda x: -len(x[1])):
    if len(v) > 1: print(k, sorted(v))
PY
```

## 八、FAQ

**Q：为什么不直接在原文里写规范名？**
A：那就改了原文。`〖@纪文达|纪昀〗` 去掉标记后仍是"纪文达"，
而 `〖@纪昀〗` 去掉标记就变成"纪昀"——原文被改了。

**Q：同一个人在不同书里规范名不同怎么办？**
A：以本名统一。本项目跨 9 部书统一（"东坡"在任何一部都指向 `苏轼`）。

**Q：`子由` 是谁？**
A：苏辙的字。**别名表里原本漏了这一条**，
导致 `古者养民如养儿子由、放翁` 的尾部出处识别失败
（详见 [SKILL_07](SKILL_07_质量反思与规律库.md) 的 Y9）。
这类"长尾字号"要靠读原文持续补。
