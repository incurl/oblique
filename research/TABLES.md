**填写规则**
1. 必须同时给出 macro（各类型 κ 的未加权平均）与 micro（全部单元汇总）两个 κ；建议在正文表格上方以脚注给出。
2. `n` 极小的类型必须报告其 CI 宽度，不得略去该行；正确读法是「本批数据不足以支持对该类型的判断」。
3. `n = 0` 的类型写「本批数据中无该类型单元」，**不得**填 0 或留空。
4. 每个 κ 必须能指出其估计量名称（Cohen's κ / weighted κ / α），并按 §5.2 同时给出 p_o、PI、BI。
5. κ 接近 1.0 且 n 小时，同时填 FCE 渐近 SE 与其 CI；若与 bootstrap CI 不一致，两者并列。
