# 投稿咨询邮件目录（Editorial Inquiries）

本目录存放**投稿前**向各目标刊物编辑部发出的咨询邮件，每封邮件一个独立文件。
所有邮件均为 **draft** 状态，发送前须先补齐「未确认事实清单」中的占位符。

> **政策口径以编辑部邮件答复为准**：本目录不写入任何未经证实的费用、稿酬、影响因子或截稿日期。
> 目录内所有涉及费用与稿酬的表述，一律以**提问**形式出现，不作断言。

## 四、使用与留痕约定

1. **一稿一投**：咨询邮件可并行发出；**论文投稿顺序必须串行**，收到答复后按优先级确定首投。
2. **首轮附件只有三件**：中英摘要、标注规范目录、1 页数据规模说明。**不附全文**。
3. **每封只问三个问题**，顺序固定：① 版面费／审稿费／加急费用；② 稿酬标准与发放方式、是否优稿优酬；③ 数据集与标注规范作为补充材料的政策（大小、格式、存储位置、审稿期能否用匿名链接）。
4. **大众稿后置**：V9 类邮件只在学术稿录用、叙事改写完成后发出，以避免版权与自我重复争议。
5. **回执留痕**：编辑部关于费用、稿酬的答复邮件，建议另存一份到 `editorial-inquiries/回执/` 备查（该目录尚未创建）。
6. **公共稿与学术稿分别撰写**：学术咨询邮件中不提及公共稿，避免重复投稿之嫌。
