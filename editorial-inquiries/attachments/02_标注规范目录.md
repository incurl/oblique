# 附件二　标注规范目录

> 本附件为投稿咨询首轮材料之二，呈现《〈楹联丛话全编〉语义标注规范》的章节目录与
> 各章要点，便于编辑部判断规范的完备程度。规范全文（约 5,200 字，含 40 余张表）拟作为
> 补充材料随稿提交，可按刊物要求转为 PDF 或附录。

---

## 一、规范的定位

规范分两层：**继承层**（直接沿用《史记》知识库 Shiji-KB 的符号体系与编号方法，本文不作改动）
与**新增层**（面向联话文体重做的联语层、关系层、属性层与领域校验）。
目录中凡标 `【继承】` 者为后者之依据，标 `【新增】` 者为本文增量。

### 第五章　联语层（本文核心）【新增】

| 节 | 内容要点 |
|---|---|
| 5.1 为什么用前置标记 | 包裹式会阻断联内实体标注，违背"不嵌套"与"可逆" |
| 5.2 联语识别规则 | 引号内 + 含分号 + 长度 5–260 + 无内嵌句号 + 分号/逗号上限 + 上下联长度比 + 排除叙述性开头 |
| 5.3 联语语料字段 | `upper`／`lower`／`type`／`author`／`place`／`context` 等 18 个字段及其可靠性分级 |
| 5.4 出处冠名：集句联的结构 | 四种位置（下联前置/后置/与正文连写、上联前置或后置）；三种形态（诗人名／「X句」缩写／文献题名） |
| 5.5 编者标记 | 「见上」「一作」「又作」的剥离；**「一曰」不属标记**的反例说明 |
| 5.6 末尾句读的剥离 | 句号属引文而非联句；不剥离会使等长率从 100% 跌至 1.4% |

### 第八章　属性层与关系层【新增】

| 节 | 内容要点 |
|---|---|
| 8.1 三类属性 | 联类（名义，11 值）／品第（序数，5 级）／时代层级（序数，4 级） |
| 8.2 联类的一值性规定 | 优先级首次命中；已知简化与代价说明 |
| 8.3 六类关系 | 撰联／题于／用典／评骘／因袭／辑录；方向固定、端点类型受限 |
| 8.4 「撰联」与「辑录」必须分开 | 创作与被记录是两种不同关系，混同会使作者网络失效 |
| 8.5 「因袭」的方向 | 由后出者指向被本者，否则因袭网络无法按时间序展开 |

### 第九章　边界判定十条规则【新增】

| 规则 | 内容 |
|---|---|
| R1 | 只加标记不改原文（零容忍） |
| R2 | 长词优先 |
| R3 | 典籍优先于其内部一切实体 |
| R4 | 地名优先于人名、神祇 |
| R5 | 同一位置不嵌套 |
| R6 | 联语以前置标记 `〖聯〗` 标识，不包裹正文 |
| R7 | 出处冠名不属于联句（形制自证：剥离后等长） |
| R8 | 编者标记不属于联句（封闭词表；「一曰」为反例） |
| **R9a** | **上下联字数平衡作为硬性领域校验**（仅在初检不平衡时启用，避免误伤工整巧对） |
| R10 | 实体边界取最小完整单位；并列专名各自成词 |

### 第十章　十条最易混淆案例【新增】

以语料真实文本为例，逐条给出「两种可能读法 → 规范判读 → 依据规则」。
覆盖：出处冠名与联句连写、编者标记「一作」、「一曰水」的切分、年号的类型归属、
庙宇名中的神祇、书名号内部实体、别名与规范名边界、并列地名的合并、同名异人、重出联。

### 第十一章　已知限制【新增】

| 限制 | 说明 |
|---|---|
| 词典覆盖 | 实体标注为词典＋规则驱动，非全量 NER；冷僻专名存在漏标 |
| 作者字段 | `author` 为高精度低召回线索；`author_near` 仅为最近人名，不保证是作者 |
| 联类启发式 | 关键词触发，一值性会丢弃次级标签 |
| 不做校勘 | 异体字、讹字、断句一律保留原文 |
| 动词层未启用 | 语法已预留，因联话以名词性描写为主，收益低、误标风险高 |
| 现代附录 | 作者简介与整理者注已隔离标记，不与原文混同 |

## 三、规范的配套物

| 配套物 | 形式 | 随稿方式 |
|---|---|---|
| 规范全文 | Markdown，约 5,200 字（含 40 余张表） | 作为补充材料 |
| 标签集与单元定义（机读） | `schema.yaml`，含 18 类实体、6 类关系、3 类属性 | 作为补充材料 |
| 修订日志 | 章末「规则变更日志」，含被实测证伪的三条做法 | 可并入规范附录 |
| 示例语料 | 20 条标注样例（覆盖 11 种联类） | 附录 |

> **可复现性**：规范中每一条可被机器判定的规则，均在脚本中落实为可执行的校验，
> 并配有回归测试。规范不是"约定俗成的说明"，而是"可被程序检验的契约"。
