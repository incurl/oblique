## 四、为何不含论文全文

咨询阶段附全文有三项风险：一是编辑部尚未表达兴趣，全文会占用审稿资源；
二是全文含大量占位符（κ、F1 等尚未产生），易被误读为数据不完整；
三是首轮邮件若附全文，后续正式投稿时「同一稿件已发出」的边界会变模糊。
三份附件已足以让编辑部判断选题、规模与规范完备程度。
